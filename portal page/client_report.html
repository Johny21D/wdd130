Client Report

I came up with the content for the site plan after seeing many cooking apps that are free but offer limited access. This inspired me to create a website where people can access recipes from around the world.

I communicated with my lead developer through Microsoft Teams individual chat. Unfortunately, the developer did not meet my expectations. I never received the portal page link that I requested. Next time, I will make sure to hire people who communicate better and deliver results.

Lead Developer

I used Microsoft Teams to create a group chat to communicate with my junior developers, but no one responded. I also sent emails, but I did not receive any replies.

I communicated with my client using Microsoft Teams, and they did respond. I shared the GitHub webpage link so the client could access the portal page.

This was my first experience using GitHub. It was interesting to explore and understand how it works.

Junior Developer

I worked as a junior developer on two teams. In one team, the lead developer never received a wireframe from the client, so there was no progress.

In the other team, communication was clear. The lead developer assigned tasks, and each junior developer completed a child page before the deadline.

I did not encounter any issues using GitHub or making changes.

General Experience Report

Most challenging part: Communication was the biggest challenge, especially when working as both a client and lead developer. Some team members did not respond or contribute.

What I enjoyed most: Writing code and seeing how design and functionality come together.

What I would do differently: I would be more persistent in communicating with junior developers and ensure tasks are clearly assigned.

Confidence: Yes, I feel more confident working on real-world projects as long as they align with my current coding knowledge.
